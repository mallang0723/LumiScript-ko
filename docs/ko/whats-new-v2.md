# v2.0 새로운 기능 (What's new in v2.0)

LumiScript 2.0은 새로운 선택적 실행 엔진을 중심으로 제작된 메이저 릴리스예요. **하위 호환성**을 완벽히 유지해요: 공개된 `api.*` 인터페이스가 변경되지 않았으므로 기존 스크립트는 수정 없이 그대로 동작해요. 메이저 버전 변경은 파괴적 변경이 아니라 새로운 엔진의 도입을 의미해요([API 안정성](api-stability.md) 참고).

> **LumiScript-ko 2.0.1+ko:** 루미버스가 직접 연결을 막아 "허용된 사설 호스트" 설정은 비활성화됐어요. 사설망 요청은 계속 차단돼요.

> **꼭 알아두어야 할 한 가지 동작 변경 — 사설망 송신 차단.** v2.0부터 **localhost / 사설 IP / IP 리터럴** 호스트로의 아웃바운드 요청이 기본적으로 차단돼요. 로컬 모델 서버(Ollama, ComfyUI, LM Studio)나 LAN 기기에 접근하는 스크립트가 있다면, **설정 → 네트워크 → 허용된 사설 호스트**에 해당 호스트를 허용 목록(allowlist)으로 등록할 때까지 요청이 거부돼요. 자세한 내용과 해결 방법은 [네트워크 송신](guides/network.md) 가이드를 참고하세요.

## 핵심 기능: QuickJS-WASM 격리(Isolate) 엔진

스크립트는 여전히 기본적으로 **AsyncFunction** 엔진에서 실행돼요 — 기존과 동일하며 장기 지원(LTS) 런타임으로 유지돼요. v2.0에서는 LumiScript 설정에서 전환할 수 있는 **선택적 QuickJS-WASM 격리** 엔진이 추가되었어요:

- 사용자 코드가 `Bun`이나 `process` 같은 호스트 전역 변수가 아예 존재하지 않는 WebAssembly VM 내부에서 실행돼요 — 단순한 `with` 스코프 섀도잉이 아닌 진정한 구조적 격리를 제공해요.
- **스크립트별 메모리 및 CPU 제한**, 한정된 컨텍스트 풀, 오작동하는 스크립트의 안전한 강제 종료 지원.
- **선택적 스크립트별 컨텍스트 격리** — 한 스크립트가 다른 스크립트의 `globalThis`나 공유 라이브러리(`z`, Handlebars 등)를 보거나 오염시킬 수 없어요.

두 엔진은 관찰 가능한 전체 인터페이스에 걸쳐 동작이 일치해요(이중 엔진 동등성 검증 하네스로 입증됨). 의도적인 소수의 차이점은 [API 안정성 → 엔진 간 차이](api-stability.md)에 정리되어 있어요. 엔진 선택 및 조정은 [실행 엔진](concepts/engine.md)을, 격리 및 워커 풀 조정은 [워커 풀](concepts/workers.md)을 참고하세요.

## 새로운 API 인터페이스

기존 코드를 깨뜨리지 않는 추가 기능들이에요 — 필요할 때 활용해 보세요:

- **`api.permissions`** — 선제적 권한 확인. `await api.permissions.has('images')` 및 `api.permissions.getGranted()`를 사용하여 권한이 필요한 메서드를 호출하기 *전에* 권한이 승인되어 있는지 미리 확인할 수 있어요. 자체 권한이 필요 없는 무료 티어예요. [권한](concepts/permissions.md) 참고.
- **`api.worldInfo` 전역 활성화** — `getGlobal` / `setGlobal` / `activateGlobal` / `deactivateGlobal`로 캐릭터/채팅 바인딩과 무관하게 모든 채팅에 적용되는 사용자의 *전역* 월드북을 관리해요. [월드 인포](guides/world-info.md) 참고.
- **`api.personas.addons`** — 사용자의 전역 페르소나 애드온 목록 조회, 읽기, 업데이트. [페르소나](guides/personas.md) 참고.
- **`api.chat.setStyleMode`** — 확장 기능이 주입한 스타일을 호스트가 얼마나 엄격하게 제한할지 설정(`bounded` vs `extension-relaxed`) — 전체 화면 오버레이나 대규모 테마 스크립트에 유용해요. [호스트 UI 테마 적용](guides/theme.md) 참고.

## 스크립트 작성자를 위한 개선: 더 정확해진 IntelliSense

편집기의 타입 힌트(Monaco IntelliSense)가 이제 수작업 유지보수 대신 **동결된 `api.*` 계약(contract)으로부터 직접 자동 생성**돼요. 자동완성과 호버 문서가 실제 구현과 어긋나지 않으며, 편집기에 표시되는 내용이 스크립트가 실제로 전달받는 인터페이스와 정확히 일치해요.

## 2.0의 기타 개선 사항

- 엔진 및 워커 풀 **진단(Diagnostics)** 패널 추가, 기술 지원 스냅샷을 위한 **보고서 다운로드** 버튼 제공.
- 아웃바운드 네트워크 보안 강화 (위에서 언급한 사설 호스트 허용 목록).
- **스크립트 팩 내보내기**가 스크립트 선택 모달 방식으로 개선됨, 사이드바 폴더에 명시적 삭제 버튼 추가, 다양한 편의 수정 사항 반영.
