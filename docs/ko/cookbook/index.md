# 쿡북 (Cookbook)

목표 지향적인 실전 레시피 모음이에요. 각 문서는 실제 작업을 위한 복사-붙여넣기 가능한 완전한 실행 코드와 핵심 설계 의도를 담고 있어요. "Hello world" 단계를 넘어 *특정한 무언가*를 만들고 싶을 때 활용하세요 — 개별 API를 하나씩 설명하는 [가이드](../index.md)와 달리, 실제 개발처럼 여러 개의 `api.*` 원시 기능을 하나의 스크립트로 엮어내는 방법을 보여줘요.

모든 레시피는 일관된 형식을 따라요: **사용할 기능** (API / 이벤트 / 권한, 가이드 링크 포함) → **스크립트 코드** (바로 실행 가능한 단일 블록) → **동작 원리** → **내 프로젝트에 맞게 응용하기** → **주의사항**.

## LLM 및 도구

- **[에이전틱 도구 루프 만들기](agentic-tool-loop.md)** — 모델이 로컬 도구를 호출하고 결과를 피드백받아 최종 답변에 도달할 때까지 반복하는 에이전트 루프.
- **[Council이 사용할 수 있는 도구 등록하기](council-tool.md)** — 스크립트와 Council 모두가 호출할 수 있는 도구(주사위 굴리기) 등록.

## 프롬프트 컨텍스트

- **[매 턴마다 동적 프롬프트 컨텍스트 주입하기](dynamic-prompt-context.md)** — 보이는 대화창을 건드리지 않고, 매 턴마다 새로운 정보를 계산하여 모델이 바라보는 프롬프트에 몰래 주입하기.

## 데이터 및 조율
