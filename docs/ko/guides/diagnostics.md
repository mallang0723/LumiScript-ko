# 진단

스크립트가 실행되지 않거나, QuickJS 스크립트가 조용히 대체 실행(fallback)되는 것 같거나, 메모리 사용량이 지나치게 높아 보일 때 가장 먼저 확인해야 할 곳이 바로 **진단** 패널이에요. 도움을 요청할 때 보고서를 내보내는 용도로도 사용돼요.

## 진단 화면 열기

LumiScript 패널을 열고 → **설정** → **지원** → **진단 보기**를 누르세요. 모달 창에 모든 하위 시스템의 실시간 상태 스냅샷이 수집돼요. **보고서 내려받기** 버튼을 누르면 시각이 기록된 Markdown 파일(`lumiscript-diagnostics-YYYY-MM-DD-HHMMSS.md`)로 저장돼요. 스크린샷 대신 이 파일을 버그 제보나 Discord 지원 채널에 붙여 넣어 전달해 주세요.

## 진단 내용 구성

보고서는 여러 섹션으로 구성되어 있으며, 각 섹션마다 *통과(pass)* / *경고(warn)* / *실패(fail)* / *정보(info)* 로 표시되는 점검 항목들이 나열돼요(*실패*는 가장 주의 깊게 살펴봐야 할 빨간색 항목으로, 보고서의 전반적인 상태를 결정해요):

- **LumiScript** — 확장 기능 수준의 상태 (활성화 여부, 버전, 주요 설정값).
- **Script-runner subprocess** — 워커 풀 상태: 살아 있는 워커 수, 워커별 메모리, 유휴/퇴출 상태. [워커 풀](../concepts/workers.md) 참고.
- **Engine** — 현재 활성화된 실행 엔진 (아래 설명).
- **Active context** — 러너가 인식하고 있는 현재 채팅 / 캐릭터.
- **Registrations** — 실시간 등록된 핸들러, 도구, 매크로, 브로드캐스트 구독.
- **Storage** — 스크립트별 저장소 사용량.
- **Assistant (Lisa)** — 앱 내 어시스턴트의 연결 상태 및 설정.
- **Editor / Monaco** — 백엔드 보고서가 도착한 후 앱에서 추가로 점검하는 브라우저 측 항목: `document.fonts` 상태와 준비 완료 여부, blob-URL 워커 지원 여부, Monaco CDN 접근성(회사 프록시나 방화벽 차단 감지 — 이 점검은 최대 약 5초 정도 걸릴 수 있어요).

## 엔진(Engine) 섹션 (v2.0)

엔진 섹션은 현재 활성화된 [엔진](../concepts/engine.md)을 반영하며, 설정에 따라 **Engine (AsyncFunction)** 또는 **Engine (QuickJS-WASM)**이라는 제목으로 표시돼요. QuickJS를 사용할 때 *"내 컴퓨터에서 격리 환경(isolate)이 정상 동작하는지, 대체 실행이 발생하지는 않았는지"*를 가장 빠르게 확인할 수 있는 곳이에요:

- **WASM 가용성** — 현재 플랫폼에서 격리 환경이 인스턴스화되었는지 여부와 콜드 스타트 시간. QuickJS로 전환한 직후 아직 스크립트가 한 번도 실행되지 않았을 때는 *not probed*로 표시되며, 첫 번째 QuickJS 실행 시 채워져요. 만약 *실패*로 나타나면 모든 QuickJS 실행이 자동으로 AsyncFunction으로 대체 실행돼요.
- **엔진별 실행 횟수** — QuickJS와 AsyncFunction 간의 실행 비율.
- **대체 실행(Degraded runs)** — QuickJS로 요청되었으나 AsyncFunction으로 물러나 실행된 횟수 (플랫폼 또는 WASM 로드 문제를 나타내는 지표). 이 숫자가 0이 아니라면 "QuickJS로 바꿨는데 아무것도 달라지지 않은" 원인을 설명해 줘요.
- **시간 초과(Timeouts)** — 발생할 때마다 하위 프로세스 전체를 다시 띄워야 하므로 시스템 안정성을 나타내는 중요한 지표예요.
- **VM 내부 메모리 부족(OOM)** — 스크립트가 컨텍스트별 메모리 상한선에 도달한 횟수 (스크립트별 격리 환경).
- **스트림(Streams)** — `generateStream`이 열린 횟수와 중간에 조기 취소된 횟수.
- **컨텍스트 풀** — 스크립트별 격리 상태일 때: 활성/최대 컨텍스트 수, 고정된 컨텍스트 수, 컨텍스트별 메모리 한도. 풀이 비활성화되는 공유 격리 상태에서는 *n/a*로 표시돼요.
